# Example: Children's H5 Game

## Scenario

An H5 game for young children has an approved concept with:

- cute illustrated farm animals
- warm pastel backgrounds
- large touch-friendly controls
- illustrated baskets, barns, crops, and reward stickers
- rounded friendly typography

## Required workflow

### 1. Concept coverage

Resolve references for:

- home / farm map
- gameplay
- hint state
- success/reward state

### 2. Asset inventory

Produce standalone assets for:

- chicken
- sheep
- cow
- duck
- rabbit
- baskets
- crops/food
- barn/pen/pond props
- reward stickers or badges

### 3. Implementation rule

Do not replace those assets with:

- emoji animals
- generic icon-library animals
- simple gray SVG sketches
- CSS cartoon shapes

### 4. Touch QA

Verify:

- artwork remains sharp at tablet size
- targets are large enough for young children
- responsive scaling does not make characters tiny
- touch feedback does not obscure artwork

### 5. Visual QA

Compare concept and browser render for:

- animal personality
- color richness
- background warmth
- card/prompt anatomy
- typography
- success feedback

If the game works but looks like a wireframe or worksheet compared with the concept, it fails visual fidelity.
